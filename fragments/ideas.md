# Why I wrote this book
When I first decided to write this book, I was young and foolish. There was a time in my life when the difficulty in doing something would be my motivating factor especially when it comes to software development and programming. So you can imagine my excitement when I first heard how difficult it is to write an operating system. My first attempt was a simple bootable program - you know the drill, the computer boots up, prints the letter 'A' at the top left hand corner and stops. Seeing my first bootable program actually boot was such a thrill that I decided to dive deeper.
